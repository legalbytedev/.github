Projektujemy, wdrażamy i utrzymujemy technologię, która wspiera codzienną pracę prawników: od aplikacji i obiegu dokumentów, przez integracje i automatyzacje, po prywatne systemy AI. Łączymy kompetencje z prawa, inżynierii oprogramowania i bezpieczeństwa informacji.

Pracujemy z kancelariami, działami prawnymi in-house i zespołami compliance w Polsce i Unii Europejskiej. Współpracujemy po polsku i angielsku.

## Co budujemy

| Obszar | Przykładowe rozwiązania |
| :--- | :--- |
| **Oprogramowanie dla kancelarii** | Portale klienckie, systemy obsługi spraw, aplikacje do pracy z umowami, intranety i narzędzia do zarządzania dokumentami. |
| **Automatyzacja dokumentów** | Generowanie dokumentów z szablonów, biblioteki klauzul, formularze i obiegi akceptacji. |
| **Integracje systemowe** | API i przepływy danych łączące systemy kancelaryjne, Microsoft 365, księgowość, rejestry publiczne oraz podpis elektroniczny. |
| **Prywatne systemy AI** | Asystenci korzystający z bazy wiedzy organizacji (RAG), analiza dokumentów i wsparcie pracy z umowami w kontrolowanym środowisku. |
| **Wtyczki Microsoft Office** | Rozszerzenia Worda, Outlooka i Excela, które udostępniają narzędzia w miejscu codziennej pracy prawników. |
| **Oprogramowanie compliance** | Rejestry, panele i procesy wspierające zarządzanie ochroną danych, ryzykiem, incydentami oraz wykorzystaniem AI. |

Zapewniamy również obsługę IT, zarządzanie chmurą i pocztą, hosting oraz utrzymanie wdrożonych systemów. Zakres dobieramy do procesów i potrzeb organizacji.

## Jak podchodzimy do technologii

- **Proces przed narzędziem.** Zaczynamy od sposobu pracy, przepływu danych i celu wdrożenia. Dopiero potem dobieramy architekturę i technologię.
- **Poufność od początku.** Tajemnica zawodowa, uprawnienia, kontrola nad danymi i wymagania organizacji są częścią projektu systemu.
- **AI pod nadzorem człowieka.** Narzędzia wspierają analizę i przygotowanie materiałów. Decyzje wymagające prawniczego osądu pozostają po stronie prawnika.
- **Możliwość dalszego rozwoju.** Stawiamy na modułową architekturę, integracje i kontrolę klienta nad jego danymi.
- **Odpowiedzialność po wdrożeniu.** Współpraca obejmuje utrzymanie, monitoring, aktualizacje i rozwój rozwiązania.

Typowy proces współpracy: **rozmowa → audyt i plan → wdrożenie → opieka i rozwój**.
